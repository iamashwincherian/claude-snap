Frequently Asked Questions

Why does macOS say the app is "damaged"?

ClaudeSnap isn't notarized by Apple (that requires a paid developer account). If you install manually instead of via install.sh, Gatekeeper reacts to the quarantine flag. Run xattr -cr /Applications/ClaudeSnap.app to fix it — the app isn't actually damaged.

Where does usage data come from?

ClaudeSnap reads Claude Code's own OAuth token from your Keychain and queries Anthropic's usage endpoint directly. Nothing is sent to a third-party server.

Does it work if the usage endpoint changes?

The usage endpoint is unofficial and reverse-engineered. If it changes shape or disappears, ClaudeSnap degrades gracefully to "unavailable" rather than breaking — your terminal still works fine.

What permissions does it need?

Accessibility permissions are needed only for the global Ctrl+` hotkey to work outside the app itself.
